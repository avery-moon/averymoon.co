# averymoon.co

Personal portfolio website for Avery Moon.

## Included
- Home
- About
- Approach
- Systems / Case Studies
- Contact
- Responsive navigation
- Neutral / green / terracotta design system
- Three starter case studies

## Publish with GitHub Pages
1. Open the `averymoon.co` repository.
2. Upload all files and folders from this project into the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment** choose **Deploy from a branch**.
5. Select branch **main** and folder **/ (root)**.
6. Save. GitHub will generate a temporary `github.io` URL.

## Custom domain
After buying `averymoon.co`, go to **Settings → Pages**, add the custom domain, then follow GitHub's DNS instructions and enable **Enforce HTTPS** after verification.
